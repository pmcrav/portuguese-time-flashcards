# Que horas são?

A Portuguese time flashcard game for PORT 1 students, with analog and digital clocks, Brazilian and European Portuguese, adjustable difficulty, and missed-card review.

## Run locally

Open `index.html` in a web browser. No installation or build step is required.

## Deploy to Netlify

Import this GitHub repository into Netlify and deploy the `main` branch.

- Build command: leave blank
- Publish directory: `.` (the repository root)

The included `netlify.toml` sets the publish directory. The site entry point is `index.html`.

## Features

- Numbered, Roman-numeral and minimal analog clocks
- 12-hour and 24-hour digital clocks
- Whole hours, quarter hours, five-minute intervals or any minute
- Brazilian and European Portuguese answer variants
- Self-assessed rounds and missed-card review
- Custom time practice on desktop
- Optional pronunciation using an installed matching Portuguese browser/device voice

No accounts, analytics, external libraries or server are required. Scores are kept only for the current round and reset on refresh.
